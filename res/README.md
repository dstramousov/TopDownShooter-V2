## Управление в 3D Map Viewer

3D Map Viewer запускается отдельной debug-утилитой:

```bash
python res/map_3d_viewer.py path/to/tactical_map.json

Viewer предназначен для свободного облёта сгенеренной карты и быстрой проверки читаемости уровня.

Основное движение
W / S        движение вперёд / назад
A / D        движение влево / вправо
Mouse        поворот камеры
Space        подняться вверх
Left Ctrl    опуститься вниз
Q            опуститься вниз
E            подняться вверх
Shift        ускорение движения
Mouse Wheel  приблизиться / отдалиться по высоте
Esc          выход
Отображение карты
G            включить / выключить grid и wire overlays
F            включить / выключить render radius
[            уменьшить render radius
]            увеличить render radius

render radius ограничивает отрисовку карты областью вокруг камеры. Это снижает нагрузку и помогает смотреть конкретный участок уровня без лишнего визуального шума.

Пресеты камеры и навигация
R            сбросить камеру в начальное положение
1            top-down view / птичий обзор
2            low fly view / низкий облёт
Home         перейти к старту S
End          перейти к цели G
Tab          перейти к следующему enemy spawn
Shift+Tab    перейти к предыдущему enemy spawn
HUD

В левом верхнем углу отображается служебная информация:

FPS
visible / total primitives
render radius on/off
текущее значение render radius
grid on/off

В правом верхнем углу отображается текущий FPS.

Viewer не является игровым режимом. Это отдельный инструмент для анализа карты: проходов, блокеров, старта, цели, enemy spawn zones и общей читаемости уровня.
